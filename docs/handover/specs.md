# Specs

The behaviour the app guarantees, as present-tense statements, each with the file that enforces it and the test that
covers it where one exists. The pages under `docs/` carry the full detail behind each line. The Swarm words, part,
slot, feed, marker and the rest, are in the [glossary](stack.md#words-used-across-these-docs).

## What the app does not do

- No admin sign-in, and no creating or managing streams. That is the admin's job ([the stack](stack.md)).
- The page holds no wallet, no stamp and no stamp key, and it never buys or manages a stamp.
- No uploads beyond chat messages.
- No theme beyond `swarm` and `web3privacy`.
- It never switches a source by itself and never falls back from one source to another.
- No test asserts a timing. Timings are reported.
